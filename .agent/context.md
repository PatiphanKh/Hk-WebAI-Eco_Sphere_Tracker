# 🌱 Eco-Sphere Tracker (Nuxt Project Context)

**Eco-Sphere Tracker** คือแอปพลิเคชันเว็บแบบ Offline-first ที่พัฒนาด้วยเฟรมเวิร์ก Nuxt.js โดยทำหน้าที่ชุบชีวิตข้อมูลพฤติกรรมการใช้ชีวิตและการเงินในอดีตของผู้ใช้จากข้อมูลดิบ (JSON) ให้กลายเป็นตัวเลขคาร์บอนฟุตพริ้นท์สะสม (kg CO₂) พร้อมแต้มสะสมรักษ์โลก (Eco Points) 

---

## 🚀 ฟีเจอร์หลัก (Key Features)
1. **Dashboard & Carbon Analytics:** แสดงผลยอดรวมคาร์บอนสะสม, สัดส่วนการปล่อยตามกิจกรรม, และแนวโน้มรายเดือนด้วยกราฟ SVG/CSS
2. **AI Eco-Advisor Chatbot:** ผู้ช่วยโค้ชสิ่งแวดล้อมวิเคราะห์พฤติกรรมอ้างอิงจากข้อมูลจริงโดยใช้ Gemini API (พร้อมระบบ Local Fallback ทำงานออฟไลน์)
3. **Real-time Carbon Simulator:** ตัวจำลองธุรกรรม ออเดอร์อาหาร และตั๋วบินใหม่เด้งเข้าแอปแบบเรียลไทม์พร้อมการคำนวณคาร์บอนสด
4. **PWA / Offline-first:** ใช้งานหน้าเว็บ คอนเทนต์การจอง และห้องแชตวิเคราะห์ข้อมูลได้ปกติแม้ไม่มีการเชื่อมต่ออินเทอร์เน็ต

---

## 📂 โครงสร้างการทำงานของไฟล์ใน Nuxt (Nuxt Project Architecture)

ระบบจะแบ่งการทำงานออกเป็นหน้าต่าง ๆ (Pages), คอมโพเนนต์ย่อย (Components), ส่วนตรรกะประมวลผล (Composables) และไฟล์ตั้งค่า ดังนี้:

### ⚙️ ไฟล์ตั้งค่าและโครงร่างหลัก (Configuration & Root)
* `package.json` - กำหนดโมดูลและ Dependencies ของโครงการ (Nuxt 3, Vite, PWA module)
* `nuxt.config.ts` - ตั้งค่าคอนฟิกูเรชันหลักของ Nuxt, การเชื่อมโยงสไตล์ CSS, และเปิดใช้งานโมดูล PWA (Service Worker)
* `app.vue` - เทมเพลตหน้าต่างหลักของระบบ กำหนดโครงสร้างหน้าจอรวมถึงแถบ Sidebar Navigation และ Header

### 📄 หน้าเว็บระบบ (Pages)
* `index.vue` - หน้าแรกของแอปพลิเคชัน แสดงสรุป KPIs ค่าคาร์บอนสะสม คะแนน Eco Points และแผนภูมิสัดส่วน
* `transactions.vue` - หน้ารวมรายการธุรกรรมทางการเงินทั้งหมดของผู้ใช้ พร้อมช่องค้นหาและตัวกรองตามประเภทรายรับ/รายจ่าย
* `tasks.vue` - หน้ารายการงานค้างและคอร์สเรียนออนไลน์ที่เป็นกิจกรรมช่วยลดหย่อนคาร์บอนและสะสมแต้ม Eco Points
* `travel.vue` - หน้ารวบรวมประวัติการสั่งอาหารเดลิเวอรี่ ประวัติสินค้าที่ช้อปปิ้ง ประวัติโรงแรม และตั๋วเที่ยวบิน
* `insights.vue` - หน้าประเมินสุขภาพโลกเชิงลึก แสดงสถิติชั่วโมงที่ใช้จ่ายสูงสุด และแสดงการ์ดคำแนะนำรักษ์โลก (Eco-Warnings)
* `chatbot.vue` - ห้องแชตถามตอบวิเคราะห์ข้อมูลการบริโภคคาร์บอนส่วนบุคคลร่วมกับ AI
* `settings.vue` - หน้าสำหรับบันทึก Gemini API Key, ปุ่มควบคุม Simulator เปิด/ปิด และปุ่มเคลียร์ฐานข้อมูล

### 🧩 คอมโพเนนต์แสดงผล (Components)
* `SidebarNavigation.vue` - แถบเมนูด้านซ้ายสำหรับเปลี่ยนหน้าเพจและตรวจสอบสถานะการเชื่อมต่อเครือข่าย
* `HeaderSection.vue` - ส่วนหัวของหน้าเว็บ แสดงชื่อหน้าปัจจุบัน ปุ่มแสดงสถานะจำลองเหตุการณ์ และแถบเลือกโปรไฟล์ผู้ใช้งาน
* `ConicChart.vue` - คอมโพเนนต์คำนวณและวาดกราฟวงกลมแยกสัดส่วนการสร้างคาร์บอน (Flights, Food, Shopping, Hotels)
* `TrendChart.vue` - คอมโพเนนต์แสดงผลกราฟแท่งเปรียบเทียบยอดการปล่อยคาร์บอนสะสมในแต่ละเดือน
* `ToastContainer.vue` - แถบแสดงกล่องข้อความเตือนเรียลไทม์มุมหน้าจอเมื่อมีข้อมูลคาร์บอนใหม่ไหลเข้าจาก Simulator

### 🧠 ตรรกะการทำงาน (Composables)
* `useDataManager.ts` - จัดการดึงข้อมูล JSON เริ่มต้น โคลนลง LocalStorage ควบคุมการเขียน/อ่านสถานะของผู้ใช้งาน
* `useSimulator.ts` - ตั้งเวลาและจำลองเหตุการณ์การทำกิจกรรมใหม่ส่งเข้าสู่ฐานข้อมูล LocalStorage แบบเรียลไทม์
* `useInsights.ts` - คำนวณปริมาณการปล่อย CO₂ แยกตามประเภทร้านอาหาร ระยะการบิน คอนเซปต์สินค้า และประมวลผลคำแนะนำสิ่งแวดล้อม
* `useAiService.ts` - วิเคราะห์คำถามประกอบบริบทข้อมูลชีวิตผู้ใช้งานเพื่อยิงไปที่ Gemini API หรือถอยมารับมือด้วย Rule-based ในเครื่องเมื่อออฟไลน์

### 🔌 ระบบเสริมภายนอก (Plugins & Service Worker)
* `pwa.client.ts` - ปลั๊กอินสำหรับการลงทะเบียนทำงานของ Service Worker เพื่อแคชไฟล์ระบบและแสดงปุ่มเตือนการใช้งานออฟไลน์
